### [Der erste Meilenstein](https://github.com/Lulon27/projektmanagement/milestone/1) 
Damit alle genügend Zeit haben, findet nächste Woche am 18.11., unserem Scrum Tag, die Besprechung zum ersten Meilenstein statt.
Bis hierhin sollten alle Gruppen eine gewisse Grundstruktur und Idee haben, mit welcher Sprache sie arbeiten und welche Api sie verwenden, damit sich alle anderen Teammitglieder hierrauf einstellen können.
Für alle [Teilgruppen](https://docs.google.com/spreadsheets/d/1OF39aJFD2xsa1V6o9rrrKWcnkTGx6LL6u8j6PGLAdEw/edit#gid=0) ist ein Issue angelegt das im [Main Board](https://github.com/Lulon27/projektmanagement/projects/1) in der Spalte "To Do" wartet.
Die Ergebnisse können dann zusammengefügt und angeglichen werden und stellen dann unsere Software Spezifikation dar.
